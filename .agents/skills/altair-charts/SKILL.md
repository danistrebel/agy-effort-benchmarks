# Generic Altair Bar & Radar Charting Skill (`altair-charts`)

## Overview

The `altair-charts` skill provides a modular, domain-agnostic toolkit for generating publication-ready, pure white-background (`#ffffff`) Altair charts from any `.csv`, `.json`, or `.jsonl` dataset, both via standalone CLI scripts and importable Python modules:

1. **[chart_theme.py](./scripts/chart_theme.py) — Shared Theme, Palettes & I/O Core**:
   - Defines 7 named color palette families (`teal`, `purple`, `amber`, `blue`, `rose`, `emerald`, `slate`), each with a 7-step light-to-dark shade scale for stacked components, solid mid-tones for scalar bars, and coordinated stroke/fill/point colors for radar polygons.
   - Provides deterministic color scale construction (`build_grouped_color_scale`), pure white canvas styling (`apply_white_theme`), generic tabular loading (`load_tabular_data`), and multi-format export (`save_chart` for `png`, `svg`, `html`, `json`).
2. **[generate_bar_charts.py](./scripts/generate_bar_charts.py) — Generic Grouped, Stacked & Faceted Bar Charts**:
   - Plots any CSV, JSON, or JSONL dataset as single-panel, column-grouped (`--group-col`), wide-stacked (`--stack-cols`), long-stacked (`--stack-col`), or multi-panel grid-faceted (`--facet-col`) bar charts.
   - Automatically aggregates repeated observations (`--agg mean|sum|median|min|max|none`).
3. **[generate_spider_charts.py](./scripts/generate_spider_charts.py) — Generic Multi-Axis Spider / Radar Charts**:
   - Plots any multi-axis CSV, JSON, or JSONL dataset on a true 1:1 aspect-ratio polygonal radar grid.
   - Auto-detects the axis column, numeric series columns, and radial scale (`--max-val`, `--rings`), and supports `--mode progressive` (`chart1`, `chart2`, ...), `combined`, `individual`, or `all`.

> [!TIP]
> For domain-specific LLM/agent benchmark evaluation runs (`results.jsonl` with token, tool call, cost, and duration breakdowns), use the companion [eval-charts](../eval-charts/SKILL.md) skill, which builds on top of `altair-charts`.

## Visual & Color Specifications

All charts generated by this skill follow strict visual design rules:

1. **White Background & Clean Styling**:
   - Canvas background: `#ffffff` (pure white) with no outer border stroke.
   - Subtle grid lines (`#f1f5f9` / `#e2e8f0`), clean axis ticks (`#cbd5e1`), and `1.2px` white bar segment dividers.
2. **Named Color Palettes & Stacked Component Gradients**:
   - Each series/group (`--group-col` or radar profile) is assigned a distinct color hue family (either automatically in order or via `--palettes GroupName=palette`).
   - Gradients are used **only for stacked segments within a group** (light-to-dark from bottom to top of the stack), while X-axis categories (`--x-col`) are distinguished by position along the X-axis. This keeps legends compact and readable:

## Step-by-Step Workflows

### Step 1: Verify the Python Virtual Environment (`.venv`)

Always use the local `.venv` Python environment to avoid PEP 668 `externally-managed-environment` errors:

```bash
.venv/bin/python -c "import altair, pandas, vl_convert" || (python3 -m venv .venv && .venv/bin/pip install altair pandas vl-convert-python)
```

---

### Workflow A: Grouped, Stacked, or Grid-Faceted Bar Charts

Use [generate_bar_charts.py](./scripts/generate_bar_charts.py) for any tabular dataset (`.csv`, `.json`, `.jsonl`):

#### 1. Grouped Scalar Bar Chart
```bash
.venv/bin/python .agents/skills/altair-charts/scripts/generate_bar_charts.py \
  --input data/metrics.csv \
  --output-dir charts \
  --output-name latency_comparison \
  --group-col series \
  --x-col tier \
  --x-order Low Medium High \
  --y-col latency_sec \
  --y-title "Average Latency (s)" \
  --title "Latency by Series and Tier"
```

#### 2. Grouped & Stacked Bar Chart (Wide Columns + Multi-Panel Facet Grid)
```bash
.venv/bin/python .agents/skills/altair-charts/scripts/generate_bar_charts.py \
  --input data/metrics.csv \
  --output-dir charts \
  --output-name breakdown \
  --facet-col scenario \
  --group-col series \
  --x-col tier \
  --stack-cols part_a part_b part_c \
  --stack-labels "Part A" "Part B" "Part C" \
  --y-title "Total Volume" \
  --y-format ",.0f" \
  --title "Component Breakdown by Scenario & Series"
```

#### CLI Options (`generate_bar_charts.py`)
- `--input` / `-i` *(required)*: Path(s) to `.csv`, `.json`, or `.jsonl` files or directories.
- `--x-col` / `-x` *(required)*: Column for X-axis bars within each group.
- `--group-col` / `-g`: Optional column to group/facet bar columns by (e.g., `series`, `provider`).
- `--y-col` / `-y`: Numeric column for scalar bar height (or long-format stack height).
- `--stack-cols`: Multiple numeric columns to unpivot and stack (wide format), with optional `--stack-labels`.
- `--stack-col`: Category column for stacked segments when data is already in long format (used with `--y-col` and optional `--stack-order`).
- `--facet-col`: Optional column to generate individual charts per facet value plus an `overview_<output-name>` multi-panel grid (`--grid-cols 2`).
- `--agg` *(default: `mean`)*: Aggregation across repeated rows (`mean`, `sum`, `median`, `min`, `max`, `none`).
- `--palettes`: Custom `Group=palette` overrides (`teal`, `purple`, `amber`, `blue`, `rose`, `emerald`, `slate`).
- `--formats` / `-f` *(default: `png svg html`)*: Output formats (`png`, `svg`, `html`, `json`).

---

### Workflow B: Multi-Axis Spider / Radar Charts

Use [generate_spider_charts.py](./scripts/generate_spider_charts.py) on any multi-axis CSV, JSON, or JSONL file:

```bash
.venv/bin/python .agents/skills/altair-charts/scripts/generate_spider_charts.py \
  --input developer/spiderchart.csv \
  --output-dir developer \
  --mode progressive
```

#### Generation Modes (`--mode`)
- `progressive` *(default)*: Generates `chart1` (1st series only), `chart2` (1st + 2nd series overlaid), ..., `chartN` (all `N` series overlaid) with identical axis labels and 1:1 coordinate geometry.
- `combined`: Generates a single radar chart overlaying all series (`<output-prefix>.{png,svg,html}`).
- `individual`: Generates one radar chart per series (`<output-prefix>_<series>.{png,svg,html}`).
- `all`: Generates progressive, individual, and combined charts in one pass.

#### CLI Options (`generate_spider_charts.py`)
- `--input` / `-i`: Path to input `.csv`, `.json`, or `.jsonl` file.
- `--output-dir` / `-o`: Destination directory for generated charts.
- `--output-prefix` *(default: `chart`)*: Filename stem prefix.
- `--axis-col` *(default: `Axis` or auto-detected first text column)*: Column name for radial axes.
- `--profiles` / `--series` / `-p` *(default: auto-detected numeric columns)*: Series columns to plot.
- `--max-val` *(default: `10.0` if max <= 10, else auto-scaled)*: Outer radial scale value.
- `--rings`: Explicit concentric ring values (defaults to 5 evenly spaced rings up to `--max-val`).
- `--palettes`: Optional `Series=palette` overrides.

---

### Step 3: Verify & Embed in Reports

1. Inspect generated `.png` charts using `read_file` to verify white background, clean labels, and color palettes.
2. When embedding charts in Markdown reports, **always use relative Markdown links** (or copy into the artifact directory if embedding in an Antigravity artifact).
